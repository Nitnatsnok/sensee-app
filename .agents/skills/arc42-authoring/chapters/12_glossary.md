# Chapter 12 — Glossary (Глоссарий)

## Purpose
Define the most important domain and technical terms used by stakeholders so everyone uses them consistently and synonyms/homonyms are avoided. May double as a translation source for multilingual teams.

## Required / recommended subsections
- A table: term · definition (optionally an extra column for translations).
- Include domain terms, project architecture terms, and code names that need disambiguation; skip obvious engineering terms.

## Form
An AsciiDoc table. In Sensee this glossary is the canonical source of term definitions and English code-names; `docs-language-review` reuses it for first-occurrence glossing, and RU/EN pairs are added here as needed rather than invented per file.

## Do not put here
- Long conceptual explanations (→ §8).
