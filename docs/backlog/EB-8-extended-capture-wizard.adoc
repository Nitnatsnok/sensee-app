= EB-8: Пошаговый ввод (wizard) поверх одностраничного захвата
:status: considering
:area: vocabulary

Триггер / что разблокирует::
Сейчас захват одностраничный (ADR-001): enrich возвращает набор смыслов,
пользователь мультивыбором добавляет нужные и/или свои, подтверждение выбора и есть
подтверждение. Пошаговый режим — возможное будущее расширение поверх этого потока
(например, сценарий «я знаю смысл, дополни его» или онбординг нового пользователя),
не альтернатива одностраничному захвату. В план не принято, по срокам не оценено.
