= EB-3: Сессия повторения по не-due подмножеству (Library / несколько дек / ручной набор)
:status: open
:area: practice

Триггер / что разблокирует::
Due-источник реализован: `Home` запускает повторение по due-подмножеству
(`PracticeConfig.DuePractice`), а сессия строится из выборки `sense_id` через
`PracticeSessionSource.Due` → `DuePracticeRepository.dueCardIds` →
`CatalogRepository.loadCards`, переиспользуя единственный планировщик FSRS (ADR-004).
Остаётся обобщить выбор состава на не-due случаи: повторение по выбранным
материалам `Library` (подмножество деки), несколько дек вперемешку, ручной набор и
опциональный дескриптор для resume. `PracticeSessionSource` уже задаёт шов —
нужно добавить новые варианты источника и их загрузку, без второго планировщика.

Связи::
* Сценарий: `docs/scenarios/home.feature` (due-источник реализован), `docs/scenarios/practice-deck.feature`
* Код: `PracticeSessionSource` (шов состава сессии), `DeckPracticeLogic.loadSession` (ветвление по источнику), `PracticeSessionPolicy` (подача внутри сессии)
* ADR: `docs/adr/0004-fsrs-is-single-scheduling-source-of-truth.adoc` (ADR-004)
* arc42: `docs/arc42/sections/06_runtime_view.adoc`
