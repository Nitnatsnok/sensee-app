= EB-3: Сессия повторения по запросу или подмножеству вместо только готового Deck
:status: open
:area: practice

Триггер / что разблокирует::
Нужна для запуска повторения из `Home` (CTA «Повторить сегодня» по due-подмножеству)
и из Practice по выбранным материалам `Library`. Сейчас сессия строится только из
готового `Deck`: `DeckPracticeLogic` грузит deck целиком, а `PracticeSessionPolicy`
определяет лишь подачу карт внутри сессии, а не её состав. Реализация переиспользует
единственный планировщик FSRS (ADR-004), без второго источника расписания.
В целевой модели сессия = **список `sense_id`** (due / подмножество деки / несколько дек
вперемешку / ручной набор), ничего не персистит (опц. дескриптор для resume), кросс-origin ок;
SRS — **на `sense_id`** (общий на наборы и сессии), так что состав сессии развязан с прогрессом.

Связи::

* Код: `DeckPracticeLogic` (загрузка готового `Deck`), `PracticeSessionPolicy` (подача внутри сессии)
