= EB-12: Правка подписанного/сервисного смысла = claim + правка
:status: open
:area: library

Триггер / что разблокирует::
Подписанные (`origin=Service`) смыслы — **зеркало**: практикуются, не правятся (ре-синк по
`source_ref` перетирает контент, SRS на `sense_id` цел). Когда нужно «работать как со своим» с
правкой — пользователь выполняет **`claim` (завладеть)**: копия в `sense` (`origin=Personal`, новый
`sense_id`, контент-снимок, **клон только FSRS-snapshot если был** — practice-op `copySnapshot`,
review-логи не дублируются), дальше правится как любой свой `Sense`. Копия
**детачнута** — обновления набора её не касаются, `derived_from` не нужен. Отдельного
copy-on-write-fork как механизма нет — это та же ядровая операция `claim` (план §2/§4). Этот пункт —
UX-аффорданс «править подписанный → предложить Завладеть» поверх ядровой механики `claim`.
