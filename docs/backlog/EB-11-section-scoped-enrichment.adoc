= EB-11: Посекционное обогащение по требованию
:status: open
:area: vocabulary

Триггер / что разблокирует::
Ручной режим даёт обогащение **всего смысла** целиком (`completeManualSense`). Когда UI
конструктора реально предложит дополнять отдельные секции `Sense` (например, только
примеры или только грамматические теги) по требованию, понадобится `EnrichmentScope`
(`WholeSense | Section(field)`) в `EnrichmentRequest`/use-case. Вводить только под этот
UI — заранее не закладываем, чтобы не плодить неиспользуемый контракт.

* Код: `EnrichmentRequest`, `SuggestVocabularySensesUseCase` (`completeManualSense`)
