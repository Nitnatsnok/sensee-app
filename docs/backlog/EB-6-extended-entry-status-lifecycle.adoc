= EB-6: Расширенный жизненный цикл EntryStatus и уборка брошенных Draft
:status: open
:area: vocabulary

Триггер / что разблокирует::
Сейчас `EntryStatus` — только `Draft`/`Confirmed`; промежуточные статусы
(`InRefinement`/`HasCandidates`) и автоматическая уборка брошенных `Draft`
отсутствуют (`deleteEntry` только ручной). Промежуточные статусы нужны вместе с
очередью незавершённых вводов в `Library`; до неё расширять перечисление
преждевременно.

Связи::
* Сценарий: `docs/scenarios/library.feature`, `docs/scenarios/home.feature`
* Код: `EntryStatus` (`Draft`/`Confirmed`), `DurableVocabularyRepository` (`deleteEntry` — ручной)
* arc42: `docs/arc42/sections/12_glossary.adoc` (Entry Status)
