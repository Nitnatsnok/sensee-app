= Backlog клиента Sensee

Каталог фиксирует отложенные доработки — продуктовые и сквозные технические, —
которые уже заметны в коде или документации, но не входят в реализованный
пользовательский срез. Открытые пункты ниже не считаются реализованным состоянием.

Один пункт — один файл `EB-<N>-<slug>.adoc`. Backlog хранит только открытые и
обдумываемые пункты: реализованный пункт удаляется (файл и строка таблицы), а не
остаётся журналом изменений — журнал ведёт история git.

== Как вести backlog

=== Добавить пункт

Взять следующий свободный ID `EB-<N>` — монотонный, без переиспользования даже
после удаления реализованных пунктов (ID цитируются в arc42, сценариях и коде).
Создать `docs/backlog/EB-<N>-<slug>.adoc` по схеме ниже и добавить строку в таблицу
«Открытые пункты» (`status: open`) или «Обдумываемое» (`status: considering`).

Схема файла-пункта:

[source,asciidoc]
----
= EB-<N>: <короткий заголовок>
:status: open
:area: <область>

Триггер / что разблокирует::
<почему отложено и что разблокирует реализация>

Связи::
* Сценарий: `docs/scenarios/<...>.feature`
* Код: `<тип/файл>`
* ADR/LikeC4: <если есть>
----

Обязательны: заголовок `= EB-<N>: ...`, атрибут `:status:` (`open` | `considering`)
и блок «Триггер / что разблокирует». Блок «Связи» рекомендуется — он делает пункт
проверяемым.

=== Обновить пункт

Менять `:status:` (`considering` ⇄ `open`), триггер и «Связи» по мере изменения
кода. Заголовок файла и строку таблицы держать согласованными.

=== Удалить пункт (реализовано)

Реализованный пункт удаляется: убрать его файл и строку из таблицы. Если пункт
реализует поведение, помеченное `@planned` в сценарии или `NOTE`-ом в arc42,
синхронно перевести его в `@implemented` / обновить текст. Реализованные пункты
здесь не накапливаются — история остаётся в git.

=== Синхронизация

Backlog — единственный список отложенного. Сценарии (`@planned`), `NOTE` в arc42 и
секция Roadmap в `README.md` ссылаются на `docs/backlog/` и ID `EB-<N>`, но не
дублируют перечень. Сопровождается skill `backlog-maintenance` (`.agents/skills`).
