= EB-7: Прямая ссылка на редактор слова через web-навигацию
:status: open
:area: navigation

Триггер / что разблокирует::
`DefaultVocabularyEditorSectionComponent` держит позицию в `MutableStateFlow`, без
Decompose-навигатора (стек/слот), поэтому секция не может быть `WebNavigationOwner`;
разбор web-URL для области vocabulary доходит только до уровня секции
(`QuickCapture`), но не до `VocabularyEditorConfig.Editor`. Разблокирует:
ввод стека/слота в секцию ради URL-параметра и реализацию `WebNavigationOwner`.

После растворения entry-агрегата (ADR-008) цель ссылки — `lemma_key`-группа слова
(открыть все смыслы леммы), а не один смысл; не-подключённый `VocabularyEditorConfig.Editor`
ещё несёт leftover-параметр `entryId`, который при реализации deep-link приводится к `lemma_key`.

Связи::
* Сценарий: `docs/scenarios/navigation.feature`
* Код: `DefaultVocabularyEditorSectionComponent` (`MutableStateFlow`), `VocabularyEditorSectionComponent` (не `WebNavigationOwner`), `VocabularyEditorConfig.Editor` (`entryId` → reconcile к `lemma_key`), `PrimarySectionConfig` (`vocabulary` → `QuickCapture`)
* arc42: `docs/arc42/sections/06_runtime_view.adoc` (web-навигация)
