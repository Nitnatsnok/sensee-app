= EB-19: Снять обход KT-85270 (инкрементальная компиляция Wasm)
:status: open
:area: build

Триггер / что разблокирует::
В `gradle.properties` отключена инкрементальная компиляция (incremental
compilation) Wasm (`kotlin.incremental.wasm=false`) как обход бага компилятора
Kotlin KT-85270: под параллельным корневым `check` инкрементальная пересборка
Wasm-тест-исполняемых падает с внутренней ошибкой компилятора `... is missing in
the map`, когда между прогонами удаляется вызов из стандартной библиотеки
(`stdlib`). Баг воспроизведён детерминированно и затрагивает текущий Kotlin
`2.4.0`; исправление доступно с `2.4.20-Beta1`, стабильная `2.4.20` ожидается
~сентябрь 2026. Когда проект перейдёт на Kotlin `>= 2.4.20`, убрать строку из
`gradle.properties` и вернуть инкрементальную компиляцию Wasm.

Связи::
* Код: `gradle.properties` (`kotlin.incremental.wasm`)
* Внешний трекер: https://youtrack.jetbrains.com/issue/KT-85270[KT-85270]
