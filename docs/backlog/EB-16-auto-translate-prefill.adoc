= EB-16: Авто-предзаполнение перевода до обогащения
:status: considering
:area: vocabulary

Триггер / что разблокирует::
При ручном вводе `translation` обязателен для confirm-gate, и пустой draft живёт до правки.
Авто-переводчик мог бы предзаполнять `translation` **до** AI-enrichment — сжимая окно пустого
draft и давая enrichment лучший контекст. Это отдельный провайдер/шов перевода; на инвариант
контекстного примера и на идентичность смысла не влияет (перевод — контент, не identity, в
`content_key` участвует нормализованно). Вводить под реальную фичу, не заранее.
