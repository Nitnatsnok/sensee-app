= Архитектурные решения

В этом разделе собраны только архитектурно значимые решения. Сами решения, их статусы и соглашения по ведению зафиксированы как отдельные ADR в `docs/adr/`; единый индекс — link:../../adr/index.adoc[ADR-коллекция клиента Sensee]. Чтобы не держать два расходящихся индекса, здесь он не дублируется. Связанные схемы эволюции клиента и продуктовых сценариев поддерживаются в `docs/c4/` (например, `vocabulary_capture_flow`).

Стратегические решения высокого уровня кратко отражены в `04_solution_strategy.adoc`; этот раздел нужен для прослеживаемости: почему решение принято, какие альтернативы рассматривались и какие последствия оно несёт. Полный список ADR, их статусы и правила ведения — в link:../../adr/index.adoc[индексе ADR].

NOTE: Отложенные доработки фиксируются в `docs/backlog/`; ADR остаются только для архитектурно значимых решений.
