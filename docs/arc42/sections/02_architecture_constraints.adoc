= Архитектурные ограничения

== Технические ограничения

* Клиентская реализация строится на Kotlin Multiplatform + Compose Multiplatform.
* Навигация и компонентные границы строятся вокруг Decompose.
* DI собирается через Metro.
* Persistence модуль строится на SQLDelight с platform-specific driver factories.
* Networking уже участвует в fixture-backed practice flow; observability выделен в отдельный shared-модуль, но пока не образует пользовательский runtime flow.
* Реальный backend API в основном пользовательском сценарии пока отсутствует.
* Платформы и source set'ы нужно поддерживать в рамках реальной структуры проекта: `androidMain`, `iosMain`, `jvmMain`, `jsMain`, `wasmJsMain` и промежуточных web source set'ов там, где они уже существуют.
* Решения должны оставаться достаточно простыми для solo-разработки и поэтапной публикации.

== Организационные / проектные ограничения

* Приоритет текущей фазы — развивать реализованный клиентский срез итеративно, сохраняя публикуемое качество инженерного результата.
* Документация для клиента должна быть standalone и не зависеть от Antora pipeline.
* Проект развивается поэтапно; на текущем шаге важнее связность и ясность, чем полнота production-инфраструктуры.
* Архитектурная документация должна оставаться согласованной с кодом репозитория и не подменять факты целевым состоянием.
* LikeC4-файлы в `docs/c4/` являются редактируемыми исходниками диаграмм; PNG-экспорты не считаются каноническим источником.

== Продуктовые ограничения

* Текущий реализованный продуктовый срез — fixture-backed practice deck, а не полный цикл обучения.
* Пользовательский сценарий должен показывать реальную ценность reusable learning deck, а не только статическую верстку.
* Текущая фаза не должна скрывать отсутствие полноценной синхронизации, live backend workflow и server-side AI orchestration.
* Shared-модули должны описываться по фактической степени подключения: `shared/srs/*`, `shared/database`, `shared/core/network` и `shared/core/mock-backend` уже участвуют в practice flow, а `shared/core/observability` пока остаётся prepared foundation.
