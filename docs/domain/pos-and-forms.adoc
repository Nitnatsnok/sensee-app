= Канон: части речи, грамматические признаки и нюансы употребления

Единый источник `GrammarUnitType` (что за единица), `GrammarTag = (GrammarCategory, GrammarForm)` (какая форма), `ComplementType`, `UsageAxis`/`UsageValue`. Все `id` — контракт обмена и хранения фикстуры `practice/grammar/taxonomy`; пользовательские подписи и сокращения выбираются во время выполнения через `GrammarLabels`. ADR, сценарии и доменная документация ссылаются сюда якорями (`#pos`, `#grammar-tags`, `#complementation`, `#usage-labels`).

NOTE: Сокращения здесь — `lexicographic`-стиль (словарная конвенция). `pedagogical`-альтернативы перечислены отдельно в <<badge-styles>>.

== Лексические единицы (POS) [[pos]]

`GrammarUnitType` — ось «что это за лексическая единица»; одно значение на смысл. RU-перевод дублируется только для двуязычного чтения, в фикстуре он живёт под BCP-47 тегом `ru`.

[options="header",cols="2,1,2,2,3"]
|===
|`id`|Short|English|Русский|Примеры

|`noun`|`n.`|Noun|Существительное|_cat_, _water_, _idea_
|`verb`|`v.`|Verb|Глагол (правильный)|_play_, _work_, _open_
|`irregular_verb`|`v. irreg.`|Irregular Verb|Неправильный глагол|_go_, _take_, _come_
|`phrasal_verb`|`phr. v.`|Phrasal Verb|Фразовый глагол|_give up_, _look after_, _turn (it) on_
|`modal_verb`|`modal`|Modal Verb|Модальный глагол|_can_, _must_, _should_, _will_
|`auxiliary_verb`|`aux. v.`|Auxiliary Verb|Вспомогательный глагол|_be_ (perfect/passive), _have_ (perfect), _do_ (negation/question)
|`adjective`|`adj.`|Adjective|Прилагательное|_big_, _interested_, _broken_
|`adverb`|`adv.`|Adverb|Наречие|_fast_, _carefully_, _well_
|`pronoun`|`pron.`|Pronoun|Местоимение|_I_, _him_, _my_, _himself_
|`determiner`|`det.`|Determiner|Определитель|_this_, _some_, _many_
|`numeral`|`num.`|Numeral|Числительное|_two_, _second_, _ten_
|`article`|`art.`|Article|Артикль|_a_, _an_, _the_
|`preposition`|`prep.`|Preposition|Предлог|_in_, _on_, _at_, _by_
|`conjunction`|`conj.`|Conjunction|Союз|_and_, _but_, _because_
|`interjection`|`interj.`|Interjection|Междометие|_oh!_, _wow!_, _ouch!_
|`idiom`|`idiom`|Idiom|Идиома (фигуральный смысл)|_a piece of cake_, _break a leg_
|`phrase`|`phrase`|Phrase|Фраза, устойчивое выражение|_by the way_, _in order to_
|===

Регулярный `verb` vs `irregular_verb` — ось *cue*, отличная от лексической: `irregular_verb` означает, что главные формы единицы (`infinitive`/`past_tense`/`past_participle`) заданы лексически и хранятся, а не выводятся правилом. `phrasal_verb` — отдельный тип, потому что несёт `separability` и набор фиксированных частиц/предлогов в `surfaceForm`. Смыслоразличающий предлог (`look at` / `look after` / `look for`) — это разные `phrasal_verb`-смыслы, не «варианты» одного.

`modal_verb` — модальные глаголы с неполной парадигмой (`can`, `must`, `should`, `will`): без `-s`, `-ing`, инфинитива с `to` и причастий. Каждая форма (`can`/`could`, `will`/`would`) — отдельный модальный смысл, а не грамматическое склонение.

`auxiliary_verb` — первичные вспомогательные глаголы `be`/`have`/`do` в своей **вспомогательной** функции (perfect/progressive/passive/вопросы/отрицания); словарная практика (Oxford OALD, Cambridge) даёт им отдельный POS-тег. Лексическое использование того же слова (`have` = «обладать», `be` = «существовать», `do` = «делать») — отдельная карточка с `irregular_verb`. Модальные глаголы — подмножество вспомогательных, но выделены отдельно из-за неполной лексической парадигмы.

=== Инвариант пары категория → форма

`GrammarForm` допустима только для своей `GrammarCategory`; каждая форма принадлежит ровно одной категории. Валидация выполняется во время работы, а не на этапе компиляции: `GrammarTag.resolve(categoryId, formId, allowedFormsByCategory)` проверяет пару против переданной таксономии (`null` = режим пропуска без проверки для офлайн/UI). Прямое конструирование `GrammarTag(...)` валидацию не делает (несёт `Unknown(...)` через границу); единая точка anti-corruption — `resolve` на AI-границе (ADR-005, ADR-006). == Комплементация (ComplementType) [[complementation]]

Что синтаксически принимает единица в этом смысле — ось `complementation: List<ComplementType>`, отдельная от `GrammarTag` и предложного управления: `enjoy`→{`noun`, `gerund`}, `want`→{`noun`, `to_infinitive`}, `make sb do`→{`bare_infinitive`}. Подсвечивается как грамматическая подсказка на карточке.

|`noun`|`+n`|noun|существительное|_enjoy a book_, _need water_
|`gerund`|`+ger`|gerund|герундий (`-ing`)|_enjoy swimming_, _avoid making noise_

== Управление предлогами и коллокации (структурная подсказка)

Помимо `GrammarTag(category, form)`, смысл несёт **структурное управление/коллокацию** — какие предлоги принимает единица в этом смысле. Это отдельная структурированная аннотация (не свободный текст в пояснении и не часть `surfaceForm`, которая описывает поверхностную форму самого смысла):

* глагол: `work` → `on` («work on»), `depend` → `on`;
* прилагательное: `interested` → `in`, `good` → `at`, `afraid` → `of`, `different` → from/to/than;
* существительное: `reason` → `for`, `increase` → `in`.

Модель: на смысле — список `PrepositionGovernment(alternatives, example?)` в `shared/grammar/domain` (обычно 0–1 группа). Каждая группа — **взаимозаменяемые** для этого *одного* смысла предлоги (`different` → from/to/than) с опциональным примером (только если не виден из контекстных употреблений). Предлоги, **меняющие смысл** (`look at` / `look after` / `look for`), здесь не группируются — это разные смыслы (сегрегация смыслов), AI возвращает их отдельными смыслами. Пустой список — единица без предложного управления. Выводится через границу AI-интеграции наравне с прочими грамматическими подсказками (ADR-001).

== Стили коротких меток: Lexicographic / Pedagogical [[badge-styles]]

Короткие метки карточек берутся из таксономии времени выполнения (`GrammarLabels.form(..., GrammarLabelForm.Short, style)` / `formByName(...)`), а не из этого канона: фикстура `practice/grammar/taxonomy` — источник истины для UI. Стилей два, ось `GrammarLabelStyle`:

* `Lexicographic` — словарная конвенция (`[T]`/`[I]`/`[C]`/`[U]`/`inf.`/`past`/`p.p.`), используется на карточке выбора смысла при вводе.
* `Pedagogical` — учебниковая ESL-конвенция (`vt.`/`vi.`/`count.`/`uncount.`/`V1`/`V2`/`V3`/`V-ing`), используется на карточке практики.

Большинство значений совпадают; ниже — только те, где `pedagogical` отличается (английские метки).

POS-уровень:

|Irregular Verb|`irregular_verb`|`v. irreg.`|`v. irr.`
|Phrase|`phrase`|`phrase`|`phr.`
|===

== Статус реализации

* Таксономия вынесена в нейтральный модуль `shared/grammar/domain` (`GrammarUnitType`, `GrammarTag`/`GrammarCategory`/`GrammarForm`, `ComplementType`, `UsageAxis`/`UsageValue`); все шесть — `sealed interface` с ветками `Unknown(id)` (ADR-006). Потребляется и capture (`vocabulary-editor`), и practice/library — независимо.
* `GrammarTag(category, form)` хранит признаки карточки/смысла, в т.ч. несколько одновременно.
* Таксономия времени выполнения — модуль `shared/grammar/data`: фикстура `practice/grammar/taxonomy` (единственный источник этого ключа), `GrammarTaxonomyRemoteDataSource`/`GrammarTaxonomySource` и два чистых снимка над фикстурой — `GrammarLabels` (`id` → пользовательская подпись с выбором языка/формы/стиля) и `TaxonomyInvariants` (`knownUnitTypeIds`, `knownComplementIds`, `allowedFormsByCategory`, `allowedValuesByAxis`). Типы-разборщики и контракты провайдеров (`GrammarLabelsProvider`, `TaxonomyInvariantsProvider`) лежат в `shared/grammar/domain` (чтобы лёгкие presentation-API и feature-домены зависели только от домена); `CachingGrammarTaxonomyProvider` делает общий запрос, а `CachingGrammarLabelsProvider`/`CachingTaxonomyInvariantsProvider` строят проекции через `toGrammarLabels()` и `toTaxonomyInvariants()`. Фикстура покрывает `unit_types` (категории/формы) с двумя `short`-стилями, `usage_axes` и `complement_types`. Потребляется и capture, и library, capture не зависит от library (ADR-001, EB-1). Фикстуры колод передают `unit_type` и `grammar_tags`.
* `GrammarCategory` разделён на `Verb` (`verb`) и `VerbIrregular` (`verb_irregular`); инвариант категория → допустимые формы проверяется во время выполнения: `GrammarTag.resolve(catId, formId, allowedFormsByCategory)` валидирует пару на AI-границе против `TaxonomyInvariants` (`null` = режим пропуска без проверки). Известные клиенту встроенные пары — `GrammarTag.knownAllowedFormsByCategory` (для офлайн-фикстур и хранения). Поверхностная форма смысла — структурный `SurfaceForm` (литерал / опциональная часть / слот) в `shared/grammar/domain`.
* Комплементация/валентность смысла — `complementation: List<ComplementType>` в `shared/grammar/domain` (`sealed interface` c известными `Noun, Gerund, ToInfinitive, BareInfinitive, ThatClause, WhClause, Adjective, PrepositionalPhrase, Intransitive` и веткой `Unknown(id)`). Незнакомый клиенту id из доверенной таксономии — `Unknown(id)`; id вне `TaxonomyInvariants.knownComplementIds` — отбрасывается на границе (ADR-006).
* Нюансы употребления — `usageLabels: List<UsageLabel>` (`UsageAxis`/`UsageValue` — sealed; парность axis ⇒ value проверяется во время выполнения через `TaxonomyInvariants.allowedValuesByAxis`); смыслоразличающий нюанс — сегрегация в отдельный смысл, не лейбл; открытое селективное ограничение — `usageNote: String?`, не проза в `explanation`.
* Контекстный пример — структурный `StudiedSentence` (`SentenceSegment.Text` / `Target`) в `shared/grammar/domain`, по тому же принципу «структура, не строка», что и `SurfaceForm`: изучаемая единица помечена источником (AI знает точный диапазон), practice подсвечивает или закрывает её для упражнения с пропуском без хрупкого подстрочного поиска (он ломался бы на словоформах `come`/`came` и разделяемых фразовых `turn it on`). Транспорт/хранение — строка с маркером `[[…]]` (как `SurfaceForm` парсится на границе).
