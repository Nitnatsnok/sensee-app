= Evolution backlog — отложенные сквозные разрывы

Живой список сознательно отложенных сквозных доработок. Это backlog-артефакт, не ADR: он мутирует (пункты добавляются, закрываются, меняют приоритет) и не несёт ADR-церемоний — поэтому политика и список живут здесь, а не в ADR (point-in-time решение и мутабельный список — разные по частоте обновления артефакты).

Политика работы с planned-разрывами:

* planned-разрыв никогда не описывается в runtime/building-block view как реализованный;
* сквозные planned-разрывы консолидируются здесь, а не размазываются по arc42/c4/сценариям; другие документы ссылаются на пункт по его `#`, а не переописывают разрыв;
* реализованный пункт уходит из живого списка в «Реализовано»; его актуальное состояние описывает соответствующий ADR/код, не changelog в backlog.
