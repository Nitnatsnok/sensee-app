== Обдумываемое (вне текущего плана)

Идеи в обсуждении: ещё не оцифрованы в backlog и не запланированы по срокам.

* Расширенный пошаговый ввод (wizard) для расширенных сценариев захвата — например, в варианте «я знаю смысл, дополни его» или для нового пользователя. Сейчас захват одностраничный (ADR-001, реализованный сценарий); пошаговый режим — возможное будущее расширение поверх него, не альтернатива.
